More reference pictures

Optional · up to 8

Add other pictures of the same character: different poses, angles or backgrounds. Each one is cut out and checked. Mark what each picture shows. A side view sets how deep the body is when it turns, back and face pictures can fill those slots, and any full-body picture can become the main front.

3D model file

Optional

Already have a 3D character? Import FBX, OBJ (with its .mtl and textures), glTF / GLB, STL, Collada (.dae), PLY or USD / USDA / USDC / USDZ. Select the model together with its texture files. Models with a skeleton are posed bone by bone, face shapes (blend shapes) move the mouth and eyes, and animations in the file can become frames.

  • Pose it like a paper doll. Arms held a little away from the body (an A-pose) give the cleanest cut-outs.
  • Any background. Plain colours, gradients, scenes and screenshots are removed automatically; transparent PNGs are used as they are. Stars, text and other separate bits are dropped.
  • Match front and back. A similar pose on both views helps. You can scale and shift the back to line it up on the Rig step.
  • Shadows or leftover background? Open Clean up cut-out and tap them with Magic remove, or paint them away.
